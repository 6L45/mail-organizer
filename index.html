Mail Organizer

Personal tool used by a single user to search, read, label, archive and trash messages in their own Gmail account.

Privacy policy

This application is used only by its developer, on their own Gmail account. It accesses Gmail data through the Gmail API with the gmail.modify scope solely to organize that account (search, read, labels, archive, trash).

  • No data is collected, stored on any server, sold or shared with third parties.
  • OAuth tokens are stored locally on the user's own machine only.
  • Access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
